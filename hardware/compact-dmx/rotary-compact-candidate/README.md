## Decisive electrical screen

IRM-10-5 is a fixed5V/2A/10W module,45.7×25.4×21.5 nominal, each dimensional tolerance±0.5. Its±2.5% output tolerance already includes setup,line and load regulation: **4.875V minimum at25°C**. Do not subtract line/load twice, assume output adjustment, or turn the3W model into a1.5A supply. Maximum ripple is200mVpp; it is not quietly treated as zero or a guaranteed symmetric±100mV waveform. Temperature coefficient±0.03%/°C applies0–50°C; no full-temperature low-voltage bound beyond it is inferred. Source:IRM-10 pp2–3.

TPS25810 power-path resistance maxima are37mΩ at25°C,46mΩ to85°C,55mΩ to125°C, specified at3A; using those resistances at1.5A is a conservative engineering DC screen, not a new characterization claim. In1.5A mode CHG=high,CHG_HI=low; short-circuit threshold1.58–1.82A. ItsCC controller advertises current, **does not regulate low VBUS upward**. TI §9 explicitly requires4.75–5.5V at the receptacle. Source§6.5,§8 and§9. A captive-cable source's different load-line allowance in USB-C R2.4§4.8.1.2 cannot be applied to this receptacle.

`screen.py` evaluates0.8/1.0/1.1m and35/70µm copper at20/80°C, with two8mm traces. Copperρ20=1.75e−8Ωm andα=.00393/°C are engineering allocations; actual finished foil resistance must be guaranteed by the flex supplier. Corner assumes width7.8mm, copper−10%,20mΩ total board/solder/termination resistance, plus55mΩ controller. The termination allocation **excludes mated connector/cable contact resistance**, so the test is not pessimistically charging cable loss to the source pin.

All12 combinations miss4.75V. Even an optimistic1m/70µm/8mm at20°C, no copper thinning, **zero termination loss**, and25°C controller37mΩ yields **4.72575V**. The explicit hot/process model is in `screen.json`; flex heating and individual drops are listed. This is enough to reject a guarantee without relying on unspecified cold, ripple or module thermal behavior.

At125°C-controller resistance, only28.33mΩ remains for the entire flex loop even with zero termination loss. At1m/80°C/8mm, that requires **190.8µm actual copper**; with the20mΩ termination allocation it requires **648.8µm**. These are mathematical break-even values before ripple, not proposed dynamic-flex constructions. Increasing trace thickness until the equation passes is not a credible compact clockspring design.

Its initial40mΩ/contact and post-test50mΩ/contact specifications concern a mated connector; equal sharing across twoVBUS/twoGND contacts would add a40/50mΩ total loop respectively, but current sharing must be established and this loss was not required to prove the source failure. ### One bounded compensation direction, not silently implemented

Retain the stationary isolated10W module but add **local regulated5.10V±1% on the rotating side, before TPS25810**, so the regulator sees and corrects flex drop. This requires a new selected buck-boost/power-stage design; no part is invented, installed or captured here. With55mΩ controller plus20mΩ downstream paths, conditional port minimum is4.9365V, leaving186.5mV for ripple/transient/additional uncertainties. This stays within5.5V at no load under the assumed regulation, but overshoot and fault limits need actual component evidence.

At90% allocated efficiency and15mW auxiliary output, input power is8.517W. With the worst screened70µm/1.1m hot FPC and the module's conditional50°C low4.8375V, solve the constant-power input quadratic: **1.843A**, regulator input **4.622V**. This is below2A nominal rating but is not startup/short-circuit/thermal qualification. A part must demonstrate the required efficiency, input range, current limit, output regulation, soft-start and protection before this can be adopted. Thick copper, extra regulator footprint and heat all affect compactness; no complete64mm packing is claimed.

IRM-10's horizontal free-air curves give full power only through50°C and≥100VAC; output derates at higher temperature and below100VAC. It is75% around60°C, which cannot supply an8.517W regulator input.77% module efficiency is typical, not worst;8.517W at77% implies about2.54W module heat, plus converter/FPC/controller heat in the enclosure. A provisional design study could restrict module-local ambient to0–40°C and line≥100VAC, but **external barrel ambient and enclosed full-load performance remain undeclared/unqualified**. All three mains end families stay stationary with PE; their connector voltage/current/endcap/approval limits remain baseline gates. This direction does not authorize a source architecture change.

### Separate connector compliance objection

The exact GCT is six-contact/power-only: no D+/D− contacts. USB-C R2.4§4.8.1.1 requires a non-data receptacle charger to advertise≥1.5A and short D+/D− below200Ω for legacy charging compatibility. TPS25810+this connector cannot implement that physical connection. This does not negate the connector's current rating or the sidecar sink candidate, but **a compliant general charger claim is unsupported**. Parent must resolve product/connector requirements before source release; no alternative family search is performed.

## Mechanical feasibility boundaries — not a motion validation

Baseline remains stationaryØ48×142,Ø84×26 collar,Ø64 index ring, approximatelyØ80 source-board allocation. Mains, PE and AC/DC module do not rotate. A64mm outer shell with1.5mm wall permits outer dynamic radius30.5; allow inner dynamic radius25 for core/bearing/barrier clearance. Proposed study construction:20mm axial width, single RA copper layer, two8mm traces separated1mm and1.5mm edge margins. A0.16mm **allocated** total flex thickness is not a supplier-approved70µm stack. No plated features/stiffener ends in the active bend; tangential clamped terminations and independent axial faces are mandatory. Minco calls for single-layer dynamic flex and avoiding plated bend conductors; neither guide certifies our bend cycle life. AllFlex static thickness-ratio examples are not promoted to dynamic endurance ratings.

A simple six-turn Archimedean spiral at radii25..30.5 has **1046.165mm** neutral length and0.9167mm pitch. `spiral-diagnostic.csv` samples181angles,−90..+90, with finite0.16mm thickness: radial interturn gap stays≥0.72mm. **But its length changes−43.589/+43.589mm** when turn count changes±0.25 with both radii fixed. It is not an inextensible cable solution, and its end tangent also changes. If length is instead held constant by letting the outer radius move, the−90° state needs **R32.912mm**, already outside the30.5mm dynamic boundary; it also breaks the fixed rotating termination radius. This falsifies that tempting procedural shortcut, **not every possible elastic clockspring**.

Accordingly no181-position collision PASS, constant-length mechanism, working hard stops or shrink STEP is fabricated. A true candidate needs an inextensible elastic strip/path model with both tangent clamps, contact/friction/finite pitch and guides, then supplier validation. Arbitrary wire torsion is rejected; no twist-life source supports it.

Axial-end USB is better than the old radialØ80 envelope, but not yet a complete pack. For example, place a1mm board with inner faceR26, topR27. GCT nominal3.16height and8.94tangential width gives outer corner radius `sqrt(30.16²+4.47²)=30.489mm`. With source drawing general±.25, use3.41height/9.19width: **R30.755mm**. Add1.25mm wall plus0.25 pose/process reserve → **OD64.51mm**, before plug opening, controller/capacitors, flex terminations or lock. Lowering board radius0.25 would approach64mm but consumes inner bearing/barrier space and needs actual footprints.Ø54 is not credible here;Ø60 is only a cassette investigation, not complete USB/lock hardware. The6.8±.15 axial connector length, finite stakes, controller/capacitors and strain relief need their own axial bay.20mm FPC+cheeks/bearings+endface electronics/lock will exceed old26mm collar width; a wider central bay might remain inside142mm core but has not been packed. No exact assembly envelope is asserted.

A separated end-face index ring is plausible geometrically:13holesØ2.2 atR28/15° have about5.11mm ligament between adjacent holes. A2mm pin with1.5mm steel ring at an **engineering1Nm abuse target** sees35.7N tangential force,11.37MPa single-shear nominal stress and11.90MPa bearing stress. These are load/stress calculations only: material allowables, fatigue, pin support, bending/engagement, ring fasteners and positive release stroke are not designed or rated. Stops must remain independent of the index pin and outside the flex bay; a missing stop track or passage cannot be excused by static stress numbers. No lock-bypass/pinch or service-assembly PASS is claimed.
