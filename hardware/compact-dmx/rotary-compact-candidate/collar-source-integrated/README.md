1. Manufacture/inspect the two connected rotor halves, stationary spool, rails, forming saddle, channel, integral-stop bridge, retainer and clamp. Qualify proposed dielectric material/process (PEEK-class prototype allocation; no sourced allowable claimed). Assemble the unchanged stationary bonds, guides, captive index spring/pin/cap and fixed flex clamp per the frozen mechanism procedure.
2. Attach the moving-tail stiffener/ear stack to the positive rotor subassembly before core insertion, using the retained inward tool passages. Preform the static tail to the developed pattern; do not force a flat rectangular ribbon into the shifted pattern.
3. Slide the unchanged source PCB into the edge rails from+X and install the external end retainer. Lay the static tongue on the J0 land/joint allocation, establish polarity, and solder through the20.8×2.8mm shell access slot. Solder-tool geometry is checked above the target joint; thermal damage and process are not simulated.
4. Seat the terminal bend on the saddle and install the external clamp. Verify covered flex, not exposed solder, is compressed. Thread/preload values require prototype qualification. The other rotor half closes around the formed fanout; frame-driver paths remain clear even in the assembled geometry.
5. Exercise the captive release and all13 positions only after physical authorization and qualified assembly. No hardware exercise was performed here. Source attach/startup/current/fault tests remain separate electrical work.

## Reproduce locally

Use the existing FreeCAD1.1.3, KiCad10.0.7 Flatpak, Python/NumPy/ReportLab and pdftoppm. From this directory, run `build.py`, `check_export.py`, `motion_check.py`, `source_contract.py`, `access.py`, `contacts.py`, `active_identity.py` and `reopen.py` with `QT_QPA_PLATFORM=offscreen /home/juicebox/.local/bin/freecadcmd <script>`. Run `flatpak run --command=python3 org.kicad.KiCad <absolute-path>/copper-check.py`; it reads but never saves the PCB. Run `python fanout.py`, `python draw.py`, render both PDFs with pdftoppm and inspect them, then `python verify.py`. Check structured outputs, not FreeCAD exit status alone. Serialization may change artifact hashes on deliberate regeneration; review the results before issuing a new receipt. Never rerun `freeze.py` to hide an input mutation.

The actual saved-file reopen was partitioned into three independent local processes with `REOPEN_GROUP=0`, `1`, `2`; `python combine_reopen.py` checks identical native/thread proofs and all eight unique STEP files. `write_receipt.py` refuses to issue a receipt unless all structured checks pass and frozen hashes still match.
