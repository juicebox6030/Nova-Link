03 / DMX-PORT UPDATES

Firmware enters through RDM.

USB-C supplies power only. Wired RDM and native NOVA-LINK wireless are the management paths. Target ANSI E1.37-4–2026 File Transfer Control for firmware delivery.

RDM updater⇄5-pin DMX / isolated RS-485⇄TI resident loader⇄SPI staging flash

Download safely

Discover the dongle UID, enter service mode, transfer acknowledged blocks to external flash, and verify the complete image before install. Selected 2 MiB AT25SF161B SPI NOR has captured connections and a checked package envelope; captured pad connections and placement are retained; routing remains open.

Recover independently

A resident loader must work with an invalid main application. A separate physical service input enters wired RDM recovery; factory cJTAG pads remain the fallback if the loader itself is damaged.

For direct wired service, unplug the female dongle from the fixture and connect a bidirectional RDM updater with a straight-through male-to-male adapter. Stop the dongle’s normal DMX output first; one controller per segment. Keep USB-C power connected.

Hardware requirements and future software behavior, not implemented firmware: TI ROM speaks UART/SPI, not RDM. An FTC-capable updater is required. Wireless delivery can share the staged-image checks later. The 10–30 s buffer does not power an entire update.
