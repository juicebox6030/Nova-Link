=== Host / Radio Transport Protocol

The portable software envelope is `[0xAA][LEN][COMMAND][DATA][CRC16]`. `LEN`
includes COMMAND (not the CRC) and is 1–103 bytes. Complete frames are 5–107
bytes. The CRC is CRC-16/CCITT-FALSE (polynomial 0x1021, initial 0xFFFF, no
reflection), sent high byte first, over LEN, COMMAND and DATA. This choice combines
the original SYNC/LEN framing concept with the command list. Physical SPI
interoperability has not been validated; see `Protocol_Decisions.md`.

==== Intended Topology

- ESP32-S3 SPI master, TI CC1352R SPI slave
- INT_READY reflects whether the radio has buffered RX fragments
- Board drivers own chip-select, clocking, padding, timeouts, and GPIO handling

[cols="1,2,3", options="header"]
|===
| Command | Meaning | Portable behavior
| 0x01 | Ping / Ready Check | Request parsed; response unspecified and unsupported
| 0x02 | Pull Received Fragment | Empty request; prepares 0xD0 frame or returns C API EMPTY
| 0x03 | Push New Fragment | Carries serialized fragment; enqueues or returns error
| 0x04 | Radio Status Request | Request parsed; response unspecified and unsupported
| 0xD0 | Fragment Data Type | Carries a radio-to-host fragment
|===

==== Golden Example

[source,text]
----
PUSH:     AA 06 03 AF FE 00 AA FF 00 C4
PULL:     AA 01 02 0E 7C
response: AA 06 D0 AF FE 00 AA FF 6A 90
----

The incremental parser handles arbitrary delivery chunks and `AA` payload bytes.
Reset partial parsing at transaction boundaries/timeouts. A CRC mismatch
rejects the frame (`NL_ERR_INTEGRITY`) and the parser hunts for the next SYNC,
so line noise and bit errors are dropped instead of delivered.
PUSH acknowledgment, empty/error response bytes, STATUS/PING replies, and remote
zone configuration require a future protocol decision. The C model's synchronous
status return is not a defined physical SPI acknowledgment.

A prepared PULL response includes an adapter-local `nl_pull_token` and remains
in the RX queue until `nl_radio_commit_pull(radio, response, token)` confirms
adapter ownership transfer. The token is never serialized on the wire and is
valid only for one radio initialization lifetime. An aborted transfer can be
retried; the commit verifies both the prepared bytes and revision token. A
coalesced replacement invalidates the token, preserving newer state even when
its bytes match a previously staged response after sequence wrap.
This does not define a physical acknowledgment or prove that a master decoded
the response.
